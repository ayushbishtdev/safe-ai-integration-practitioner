# data/

## safe-ai-metrics.csv

Key statistics, benchmarks, and figures from the SAFe 6.0 AI Integration Survival Guide series. Useful for building internal presentations, business cases, and training materials without having to re-read the full articles.

### Column definitions

| Column | Description |
|---|---|
| `metric` | What is being measured |
| `value` | The numeric value |
| `unit` | Unit of measurement (percent, USD, roles, steps, etc.) |
| `context` | Brief note on how to interpret the figure |
| `source_article` | Slug of the article where this figure appears |

### Sources

All figures traced to the Scrum.org AI4Agile Practitioners Report 2026 (289 practitioners, 20+ countries) or SAFe 6.0 guidance from Scaled Agile, Inc., as cited in the source article series at [agileleadershipdayindia.org](https://agileleadershipdayindia.org/blogs/safe-6-ai-integration-survival-guide/).

### Update cadence

Updated quarterly. If a figure has changed or a better source is available, open an issue or submit a PR with the corrected number and source URL.
